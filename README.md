# Índice Público

**Política analisada por dados, não por torcida.**

O Índice Público é uma plataforma de análise de desempenho político baseada em dados públicos, metodologia matemática auditável e inteligência artificial explicável.

## Princípios

- Dados públicos e fontes identificáveis.
- Metodologia pública, versionada e reproduzível.
- A mesma entrada produz o mesmo resultado na mesma versão.
- IA processa, normaliza, verifica e explica dados; não decide quem é “melhor”.
- Ideologia não é critério de mérito.
- Investigação, acusação, processo, decisão e condenação não são tratados como a mesma coisa.
- Dado ausente ou não verificável não vira automaticamente zero.
- Todo resultado deve permitir rastreamento até o dado de origem.

## Metodologia v1.0 — proposta

| Dimensão | Peso |
|---|---:|
| Participação e assiduidade | 15% |
| Atuação legislativa | 20% |
| Votações e posicionamentos documentados | 10% |
| Uso de recursos públicos | 15% |
| Transparência | 15% |
| Compromissos verificáveis | 10% |
| Integridade documental/jurídica | 10% |
| Prestação de contas eleitoral | 5% |
| **Total** | **100%** |

> A metodologia v1.0 ainda é uma proposta. Pesos e fórmulas só devem ser considerados definitivos após revisão e publicação de uma versão formal.
