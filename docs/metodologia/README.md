# Metodologia

A metodologia define como dados públicos são transformados em indicadores e em uma pontuação de 0 a 100.

## Requisitos

Toda metodologia deve ser:

1. Pública.
2. Reproduzível.
3. Auditável.
4. Determinística.
5. Versionada.
6. Independente de preferências partidárias ou ideológicas.

## Dados ausentes

Dados ausentes, incompletos ou não verificáveis devem ser identificados explicitamente. Não devem ser convertidos automaticamente em desempenho zero ou máximo.

O sistema deverá apresentar também a cobertura dos dados utilizada em cada avaliação.
