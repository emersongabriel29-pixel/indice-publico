# Auditoria

O Índice Público deve permitir que qualquer pessoa entenda de onde veio uma pontuação.

## Cadeia de auditoria

Pontuação → dimensão → indicador → valor bruto → transformação → fórmula → peso → fonte → documento original.

## Princípios

### Rastreabilidade
Todo dado relevante precisa ter origem identificável.

### Reprodutibilidade
O cálculo deve poder ser repetido com os mesmos dados e a mesma versão metodológica.

### Imutabilidade histórica
Resultados publicados devem preservar a versão metodológica e os dados utilizados.

### Transparência de alterações
Correções de dados devem registrar o que mudou e por quê.

### Ausência não é zero
Informação inexistente ou não verificável deve aparecer como ausência ou baixa cobertura, e não como nota zero automática.

### Separação entre fato e interpretação
O sistema deve separar o dado oficial da interpretação apresentada ao usuário.

### Testes anti-manipulação
O resultado não deve mudar por ordem dos políticos, nome visualizado ou posição no ranking. Entradas idênticas devem produzir resultados idênticos.
