# Fontes de dados

A prioridade é utilizar fontes primárias e oficiais.

## Prioridade inicial

1. Câmara dos Deputados
2. Tribunal Superior Eleitoral — TSE
3. Senado Federal

Fontes jornalísticas, redes sociais e agregadores podem servir como contexto ou descoberta, mas não devem substituir o documento oficial quando houver fonte primária disponível.

Cada dado armazenado deverá possuir referência de origem, data de coleta e, quando aplicável, identificador oficial.

## Câmara dos Deputados

Fonte prioritária para o MVP de deputados federais:

https://dadosabertos.camara.leg.br/

## TSE

Fonte oficial para candidaturas, bens declarados, resultados eleitorais e prestação de contas:

https://www.tse.jus.br/

## Senado Federal

Fonte oficial para dados relacionados a senadores e atividade legislativa:

https://www12.senado.leg.br/
