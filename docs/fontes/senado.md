# Fonte oficial — Senado Federal

## Finalidade

O Senado Federal é fonte primária para dados relativos à atuação dos senadores.

## Dados a coletar

Conforme disponibilidade oficial:

- identificação;
- partido e UF;
- mandato;
- presença;
- votações;
- proposições;
- relatorias;
- comissões;
- despesas;
- atos e informações institucionais;
- demais dados necessários aos indicadores definidos na metodologia.

## Regras

- preservar o identificador oficial;
- registrar período e mandato;
- guardar fonte e data de coleta;
- armazenar dados brutos;
- normalizar sem apagar o valor original;
- diferenciar ausência de dado de zero;
- registrar correções e revisões.

## Auditoria

Todo resultado derivado de dados do Senado deve permitir chegar ao registro oficial usado no cálculo.

## Uso no Índice Público

Os dados são utilizados exclusivamente nos indicadores definidos para senadores e em informações descritivas compatíveis com o perfil político.
